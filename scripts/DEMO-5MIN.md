# NEXUS — 5-Minute Live Demo Script

Use this for investor pitches, workshops, or conference demos.  
**Login:** `commander` / `nexus123` · **URL:** http://localhost:5173/command

---

## Quick start (automated)

1. Start stack: `.\scripts\start.ps1`
2. Open Command Center → click **5-Min Demo** (دمو ۵ دقیقه) in the bottom tab bar
3. Follow the on-screen guide card (top-right). Skip anytime with **Skip tour**

This runs **Demo Lite** (10 visual effects, smooth performance) and auto-advances through tabs.

## Manual script (~5 minutes)

| Time | Action | What to say |
|------|--------|-------------|
| **0:00** | Open `/command`. Point at metrics bar (100% green). | "NEXUS is a digital twin of Washington D.C. — live infrastructure health." |
| **0:30** | Visual Wow → **Demo Lite** (or it auto-loads). | "Ten cinematic layers tuned for demo — not 31 at once." |
| **1:00** | Left panel: select **Earthquake**, magnitude 7, **Arm map**, click center. | "We trigger a crisis. EBS alert + seismic rings fire automatically." |
| **1:45** | Pan/zoom map. Show heatmap, SOS ripples if any. | "Operators see panic spread and epicenter shockwaves in real time." |
| **2:15** | Bottom tabs → **War Room** → Start → submit a decision as Mayor. | "Multi-stakeholder decisions — Mayor, FEMA, Media — with conflicts." |
| **2:45** | Tab → **SOS** → show dispatch. | "Citizen SOS syncs instantly to the 3D map." |
| **3:15** | Tab → **Mayor** → pick a recovery choice. | "Every choice shifts satisfaction and media pressure." |
| **3:45** | Left panel → **Enable Recovery**. Drag **Before/After** slider on map. | "Scrub from crisis damage to recovery — strong visual for stakeholders." |
| **4:15** | Tab → **Timeline** → scrub ticks. | "Full audit trail — every event timestamped." |
| **4:45** | Visual Wow → **Generate Crisis Wrapped** → Share. | "Spotify-style score card — grade, trust, SOS resolved — ready to share." |
| **5:00** | Optional: **Full Demo** button for all 31 FX + cinema. | "For the wow finish, we enable the full cinematic stack." |

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Map won't pan | Turn off **Photo Mode** (📷 in map toolbar) |
| UI cluttered | Click **Demo Lite** in Visual Wow panel |
| Backend offline | Run `.\scripts\start.ps1`, wait for port 8000 |
| EBS didn't show | Visual Wow → toggle EBS on, or trigger a new disaster |
